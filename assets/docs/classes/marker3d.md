# Marker3D

> class Marker3D
> inherits Marker3D Node3D

## Brief

Generic 3D position hint for editing.

## Description

Generic 3D position hint for editing. It's just like a plain `Node3D`, but it displays as a cross in the 3D editor at all times.

## Properties

> property gizmo_extents : float ; default=0.25 ; setter=set_gizmo_extents ; getter=get_gizmo_extents

Size of the gizmo cross that appears in the editor.
