# CanvasModulate

> class CanvasModulate ; keywords=color
> inherits CanvasModulate Node2D

## Brief

A node that applies a color tint to a canvas.

## Description

`CanvasModulate` applies a color tint to all nodes on a canvas. Only one can be used to tint a canvas, but `CanvasLayer`s can be used to render things independently.

## Properties

> property color : Color ; default=Color(1, 1, 1, 1) ; setter=set_color ; getter=get_color

The tint color to apply.
