# ColorRect

> class ColorRect
> inherits ColorRect Control

## Brief

A control that displays a solid color rectangle.

## Description

Displays a rectangle filled with a solid `color`. If you need to display the border alone, consider using a `Panel` instead.

## Properties

> property color : Color ; default=Color(1, 1, 1, 1) ; setter=set_color ; getter=get_color

The fill color of the rectangle.
