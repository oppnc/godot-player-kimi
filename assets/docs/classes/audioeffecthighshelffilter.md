# AudioEffectHighShelfFilter

> class AudioEffectHighShelfFilter
> inherits AudioEffectHighShelfFilter AudioEffectFilter

## Brief

Adds a high-shelf filter to an audio bus.

## Description

A "high-shelf" filter controls the gain of all frequencies above `AudioEffectFilter.cutoff_hz`.
This filter can be used to increase or decrease clarity of a sound.
